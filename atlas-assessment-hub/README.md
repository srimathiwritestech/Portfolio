# Atlas Assessment Hub

A fictional enterprise assessment product created as a UX writing / content design portfolio project.

## What this demonstrates

- End-to-end enterprise workflow design
- UX writing across onboarding, forms, questionnaires, errors, status, review and completion
- Role-aware product experiences (SMPO / Client)
- Microcopy in context rather than isolated examples
- Content hierarchy and progressive disclosure
- Status language and recovery guidance
- Interactive prototype behavior
- Local browser state for the selected role

## Product workflow

Opportunity → Questionnaire Template → Questionnaire Creation → Client Response → SMPO Review → Completed Assessment → Export

## Important

This is a fictional product. It is not an IBM product and does not reproduce confidential product UI or content.

## GitHub Pages

This is intentionally built as plain HTML/CSS/JavaScript so it can be hosted directly on GitHub Pages. GitHub Pages publishes static files from a repository, so this prototype does not require a server to demonstrate the UX. A production version could later connect the same interface to a real backend/authentication layer.

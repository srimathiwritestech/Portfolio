# Srimathi R — Portfolio Website

A complete static portfolio website designed for GitHub Pages.

## Edit only these areas
- `index.html` — homepage copy and featured projects
- `about.html` — bio, approach and skills
- `contact.html` — email, LinkedIn and GitHub
- `projects/*.html` — case-study content

The design, responsive layout, navigation and styling are already implemented in `css/style.css` and `js/main.js`.

## Publish
Copy the contents into your existing GitHub Pages repository and push to your main branch. No build step is required.

## Before publishing
Replace the placeholder contact links. Review all case studies and replace the example/sanitized content with material you are authorized to publish. Do not publish confidential company information or internal screenshots.
